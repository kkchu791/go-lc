### Algo that determine undirected graph contains a cycle O(V)

Counting bounds

For undirected graphs, **|E| <= |V| - 1**, this must be true for the graph to be acyclic.

Undirected graph is acyclic (i.e, a forest) if and only if a DFS yields no back edges.

    If there's a back edge, there's a cycle
    If there's no back edge, there are only tree edges.

    Hence, the graph is acyclic.

Thus, we can run DFS: if we find a back edge, there's a cycle

Time: O(V) - if we ever see |V| distinct edges, we must have seen a back edge because in an acyclic undirected forest, |E|≤|V|−1 (Theorem B.2)
