### What if Kahns Aglo was run a graph with a cycle?

I noticed you can't finish the whole graph because the cycle won't let the node get to 0 indegrees, so you can't add any more to the queue and traversing stops.

This leads to incomplete traversal of the graph.

You can compare n number of nodes to how many nodes you've popped from the queue. If the numbers don't match you know you have a cycle.
