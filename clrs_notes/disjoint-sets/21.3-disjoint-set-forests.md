### Disjoint Set Forests 

Each member pints only to its parent.

2 Heuristics
"Union by Rank"
 - rank -> upper bound on the height of the node.
 - we make the root w/ smaller rang point to the root with larger rank during a Union operation
"Path compression"
 - used during FIND-SET operations to make each node on the find path point directly to the root

	Note: Path compression does not change ranks

Asymptocically optimal - no other algo can perform a sequence of operations with a better growth rate in the limit as input size approaches infinity.

MAKE-SET - creates a tree w/ one node

FIND-SET - by following parent pointers until we find the root of the tree
			and then go back down to assign the nodes to the root

			Nodes visited on this simple path toward the root constitute the **find path**.

UNION - causes the root of one tree to point to the root of the other.

Heuristics to improve the running time
	Using 2 heuristics gets us almost linear in the total num of operation in.

**Pseudocode for Disjoint Sets**

Union by Rank Sequence
	1. Keeps track of ranks
		a. with each node x, maintain the integer value x.rank.
			The upper bound on the heigh of x.
			 The num of edges in the longest simple path from a descendant leaf to x
	Make-Set creates a singleton set with rank of zero

	Union - If roots have unequal rank
	-> Make the root w/ higher rank the parent of the root w/ lower rank.

		If roots equal rank
		-> arbitrarily choose one of the roots as the parent and increment its rank.

Parent of node x = x.p

```

MAKE-SET(x)
x.p = x
x.rank = 0

UNION(x, y)
	LINK(FIND-SET(x), FIND-SET(y))
	
	
LINK(x, y)
	if x.rank > y.rank
		y.p = x
		
	else x.p == y
		if x.rank == y.rank
			y.rank = y.rank + 1
			
FIND-SET(x)

	if x does not equal x.p
		x.p = FIND-SET(x.p)
	return x.p
```


FIND-SET is 2 pass recursive

	One pass UP to find path to the find the root
		Second pass DOWN to find path to update each node to point directly to the root.
