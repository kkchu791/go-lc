### 21.2 Linked-List Representation of Disjoint Sets

each set is represented by its own linked list

The **representative** is a the set member first in the list

MAKE-SET O(1) time -> creates new linked list with x as the only object in it
FIND-SET O(1) time ->follow the pointer from x back to its set object
				-> return the member int he object that head points to
