FIND-SET(x): Returns the set object that contains element x (typically using x's back-pointer to its set object).


```
FIND-SET(x Node)
 return x.setP
```

Compare their size fields to see which is larger (weighted-union heuristic).

Append the smaller set's list onto the end of the larger set's list.

Loop through the smaller list to update each node's setP to point to the larger set.

```
UNION(x, y Nodes)

// find there set
sX = FIND-SET(x)
sY = FIND-SET(y)

if sX == sY (these two are already in the same set)
    return 

if sX.size >= sY.size
    // append Sy onto Sx
    sX.tail.next = sY.head
    sX.tail = sY.tail
    sX.size += sY.size
    
    currEl = sY.head
    for currEl != nil
        currEl.setP = sX
        currEl = currEl.next


else
    sY.tail.next = sX.head
    sY.tail = sX.tail
    sY.size += sX.size

    currEl = sX.head
    while currEl != nil
        currEl.setP = sY
        currEl = currEl.next
```
