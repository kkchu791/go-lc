```
UNION(x, y Nodes)

// find there set
sX = FIND-SET(x)
sY = FIND-SET(y)

if sX == sY (these two are already in the same set)
    return 

if sX.size >= sY.size
    // append Sy onto Sx
    sX.tail.next = sY.head
    sX.tail = sY.tail
    sX.size += sY.size
    
    currEl = sY.head
    for currEl != nil
        currEl.setP = sX
        currEl = currEl.next


else
    sY.tail.next = sX.head
    sY.tail = sX.tail
    sY.size += sX.size

    currEl = sX.head
    while currEl != nil
        currEl.setP = sY
        currEl = currEl.next
```

O(m + nlogn)

nlogn is worst case for  sequence of all n-1 possible union operations combined

n is the number of nodes

nlogn is the worst-case time for ALL n-1 union operations combined

m is the total list of operations performed (make-set, find-set, union)
