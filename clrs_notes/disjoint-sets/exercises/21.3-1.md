Using a disjoing set forest with union by rank and path compression

Node
val int
parent *Node
rank int

Node x
val 0
parent nil
rank nil

make-set(x *Node)
x.parent = x
x.rank = 0


find-set(x *Node)
if x does not equal x.p
  x.p = FIND-SET(x.p)
return x.p

Union(x, y)
    Link(Find-Set(x), Find-set(y))

Link(x, y)
    if x.rank > y.rank
        y.p = x

    else
        x.p = y
        if x.rank == y.rank
            y.rank = y.rank + 1
