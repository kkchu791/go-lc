21.1 Disjoint-set operations

**Representative** - a member of the set

Operations:
	Make-Set(x) - creates a new set whose only member (thus representative) is x.

	Union(x, y) - combines SetX and SetY

		Find-Set(x) - returns a pointer to the representative pf the set containing x


An application of disjoint-set data structures

Ex: best use: finding connected components of an undirectred graph

Connected-Components - computed components in a graph
Same-Component - answer if 2 vertices are in the same connected component

```
Connected-Components(G)
	for each vertex v subset of G.V
		MAKE-SET(V)
		
	for each edge(u,v) subset G.E
		if FIND-SET(u) does not equal FIND-SET(v)
			UNION(u, v)
```

```
SAME-COMPONENT(u,v)
	if FIND-SET(u) == FIND-SET(v)
		return TRUE
	else return FALSE
```
